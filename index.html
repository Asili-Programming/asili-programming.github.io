Asili · Origin / Nature

Write programs in Swahili.

Asili is a programming language whose keywords and standard library are Swahili. Pata is its toolchain: compiler, runner, formatter, linter and language server, with native code as the only way a program runs.

Get started View on GitHub

A first program

The entry point is kuu. weka declares a value, and chapisha prints it.

leta hisabati

kazi kuu(hoja: Orodha<Neno>) -> Tupu {
  weka j = jumla(2, 3)
  chapisha("jumla(2, 3) = " + (j kama Neno))
}

Keywords: kazi (function), weka (let), ikiwa (if), linganisha (match), rejesha (return).

What is here

The language

Swahili keywords, typed values, Chaguo<T> and Tokeo<T,E> instead of null and exceptions, structs and impls.

Language tour →

Pata, the toolchain

The pata CLI builds and runs programs, and includes a formatter (nadhifu), a linter, a package resolver and a language server (mwalimu).

CLI reference →

Standard library

Modules for files, time, math, networking (HTTP, WebSocket, TLS), concurrency and more, with Swahili names throughout.

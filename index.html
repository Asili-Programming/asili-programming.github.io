Asili · Lugha ya programuAsili · A programming language

Andika programu kwa Kiswahili.Write programs in Swahili.

Asili ni lugha ya programu ambayo maneno yake ya kuandikia msimbo na maktaba yake ya kawaida ni ya Kiswahili. Pata ni zana yake: kikusanyaji, kiendeshi, nadhifu (kipangaji cha msimbo), kikagua msimbo na mwalimu (seva ya LSP kwa wahariri). Programu zote huendeshwa kama msimbo wa mashine asilia; hakuna mkalimani. Asili is a programming language whose keywords and standard library are in Swahili. Pata is its toolchain: compiler, runner, formatter (nadhifu), linter and language server (mwalimu). Every program runs as native machine code; there is no interpreter.

Programu ya kwanzaA first program

Kiingilio cha programu ni kuu. weka hutangaza thamani, na chapisha huichapisha.The entry point is kuu. weka declares a value, and chapisha prints it.

leta hisabati

kazi kuu(hoja: Orodha<Neno>) -> Tupu {
  weka j = jumla(2, 3)
  chapisha("jumla(2, 3) = " + (j kama Neno))
}

kazi (kazi), weka (tangaza thamani), ikiwa (sharti), linganisha (linganisha thamani), rejesha (rudisha matokeo), leta (ingiza moduli). kazi (function), weka (let), ikiwa (if), linganisha (match), rejesha (return), leta (import a module).

Kwa nini Asili?Why Asili?

Maneno ya KiswahiliSwahili keywords

Msimbo unasomeka kwa Kiswahili tangu neno la kwanza, na majina ya maktaba ni ya Kiswahili pia.Code reads in Swahili from the first word, and library names are Swahili too.

Hakuna null wala makosa yaliyofichwaNo null, no hidden exceptions

Thamani inayoweza kukosekana ni Chaguo<T>. Kosa linarudishwa kama Tokeo<T, E>, kwa hiyo unaliona kwenye aina ya kazi.A value that may be missing is Chaguo<T>. An error comes back as Tokeo<T, E>, so it shows in the function's type.

Msimbo asilia tuNative code only

Programu hukusanywa kuwa msimbo wa mashine (x86-64, AArch64) au moduli ya wasm kwa kivinjari. Hakuna mkalimani.Programs compile to machine code (x86-64, AArch64) or a wasm module for the browser. There is no interpreter.

KasiSpeed

Kwenye benchmark ya Sudoku (kutatua fumbo moja kwa kurudi nyuma, majaribio 90,665), Asili huendesha kwa kasi karibu sawa na C iliyokusanywa kwa clang -O2.On the Sudoku benchmark (solving one puzzle by backtracking, 90,665 attempts), Asili runs close to C built with clang -O2.

UtekelezajiImplementationMudaTime
C (clang -O2)6.5 ms
Rust (-O)6.8 ms
Asili (asilia, nguvunative, nguvu)7.2 ms
C (gcc -O2)8.1 ms
Python 3302 ms

Muda wa mchakato mzima kwenye core moja, pamoja na takriban 3.3 ms za kuanzisha mchakato. Nambari hizi ni za kawaida, si ahadi; zinatoka kwenye examples/sudoku.Whole-process time on one core, including about 3.3 ms of process start-up. These are typical results, not guarantees; they come from examples/sudoku.

Majukwaa yanayoungwa mkonoSupported targets

  • x86-64 na AArch64: msimbo asilia kupitia pata jenga.x86-64 and AArch64: native code through pata jenga.
  • Kivinjari (wasm): moduli ya wasm inayoendesha uwanja wa kivinjari.Browser (wasm): a wasm module that runs the browser playground.
  • Cortex-M: msimbo wa strict kwa pata jenga --lengo cortex-m.Cortex-M: strict code for pata jenga --lengo cortex-m.

Maktaba ya kawaidaStandard library

  • msingi: aina na viunda vya msingi (bila leta)basic types and constructors (no leta needed)
  • hisabati: hesabu, trigonometria, logi na namba za nasibuarithmetic, trigonometry, logarithms and random numbers
  • mfumo: mazingira, JSON, mtandao (TCP, TLS, HTTP) na isharaenvironment, JSON, networking (TCP, TLS, HTTP) and signals
  • majira: saa, tarehe na muda (UTC)time, dates and durations (UTC)
  • matumizi: kuandika na kusoma kwenye skrinireading and writing the terminal
  • faili: kusoma na kuandika faili, saraka na njiareading and writing files, directories and paths
  • sambamba: nyuzi, kazi sawia, njia za ujumbe na kufulithreads, async tasks, message channels and locks
  • usimbaji: base64, hex, hashi na vitambulishobase64, hex, hashes and identifiers
  • ruwaza: misemo ya kawaida (Unicode)regular expressions (Unicode)
  • runtime: habari za kitekelezi na mfumo kinachoendeshwainformation about the runtime and the host system
  • syscall: wito wa moja kwa moja kwa kerneldirect calls to the kernel
  • kasha_gc: thamani inayoshirikiwa kwa kuhesabu marejeo (si ya lazima)shared values with reference counting (optional)

Pata, zana ya AsiliPata, the Asili toolchain

  • pata jenga: hujenga msimbo wa mashine; pata jenga --tenda huendesha mara moja.builds native code; pata jenga --tenda builds and runs.
  • nadhifu: hupanga msimbo wako kwa mtindo mmoja.formats your code in one consistent style.
  • mwalimu: seva ya LSP inayoleta kukamilisha maneno, makosa na kuruka kwenye ufafanuzi kwenye wahariri.the language server: completion, diagnostics and go-to-definition in editors.

Kwa walimuFor teachers

Programu fupi za mfano zinazofaa somo moja ziko kwenye uwanja: karibu (ujumbe wa kwanza), sifa (umbo na mbinu) na makosa (makosa na jinsi ya kuyashughulikia).Short sample programs that fit one lesson are in the playground: karibu (a first message), sifa (structs and methods) and makosa (errors and how to handle them).

Kila mwanafunzi anaweza kufungua uwanja wa kivinjari na kuendesha msimbo bila kusakinisha chochote.Every student can open the browser playground and run code without installing anything.

# Website planning documents

The plan for asili-programming.github.io, read in this order:

| # | Document | What it settles |
| --- | --- | --- |
| 1 | [Product Requirements](01-product-requirements.md) | Goals, audiences, scope, FR and NFR requirements, metrics |
| 2 | [Technical Requirements](02-technical-requirements.md) | Architecture, Zola, URL map, playground build, languages, CI |
| 3 | [App Flow](03-app-flow.md) | Site map, navigation, user journeys, playground states, edge cases |
| 4 | [Design Brief](04-design-brief.md) | Brand, voice, colour tokens, typography, home page layout |
| 5 | [Implementation Plan](05-implementation-plan.md) | Roadmap, task tracker, decisions, launch checklist |

Requirement IDs (FR-n, NFR-n) are defined in the Product Requirements and used by the other four.
Change these documents by pull request, like code. When a decision changes, update every document
that mentions it in the same pull request.

This folder is not part of the published site.
